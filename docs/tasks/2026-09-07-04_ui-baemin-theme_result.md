# UI 리디자인 결과 — 배달의민족 톤 (Brownfield 챌린지 A)

Written at (KST): 2026-09-07 22:30

## 왜 했는가
동작하는 MVP는 기본 주황 톤이라 실제 서비스 느낌이 약했다. 고객·관리자 화면을
**배달의민족 브랜드 톤**(민트 포인트 + 둥글고 친근한 타이포)으로 리디자인해 실서비스
같은 인상을 주도록 했다. 기능은 그대로 두고 시각 레이어만 바꾸는 Brownfield 개선이다.

## 무엇이 바뀌었는가
CSS와 두 HTML의 폰트 링크만 변경했다. 마크업 구조·클래스·JS·API·인증·SSE는
일절 손대지 않아 동작은 이전과 동일하다.

- **컬러**: 포인트 컬러를 주황(`#d94f30`)에서 **배민 민트(`#2AC1BC`, hover `#1EA7A2`)** 로
  교체. 배경은 더 밝고 깔끔하게(`#f7f8fa`), 텍스트 잉크는 부드러운 다크(`#2b2f36`).
- **타이포**: 제목·버튼·탭·배지·표 헤더에 **주아체(Google Fonts "Jua")**, 가격·수치 강조에
  **도현체("Do Hyeon")**. 본문은 가독성 위해 시스템 폰트 유지. 두 화면 `<head>`에
  `preconnect` + Google Fonts `<link>` 추가. 오프라인/차단 시 둥근 시스템 폰트로 fallback.
- **형태/촉감**: 모서리 반경 확대(카드 16px, 버튼/입력 12px), 부드러운 그림자와 hover 시
  떠오르는 효과(메뉴·테이블 카드), 버튼 최소 높이 44px로 터치 친화, 메뉴 이미지
  120→150px 확대, 입력 포커스 링(민트) 추가.
- **상태 배지**: 접수(pending)를 민트 하이라이트로, 준비중(amber)·완료(green)는 유지해
  구분을 지켰다. 실시간 신규 강조(`is-new` flash)도 민트 톤으로 조정.

## 검증
- 백엔드 테스트 37개 통과(코드 무변경 → 무회귀 확인).
- 프론트 JS 3개 `node --check` 무손상.
- uvicorn 실서버 스모크: 고객 `/`·관리자 `/admin` 200, CSS에 민트색 반영, 두 페이지에
  폰트 링크 존재, 테이블 인증·관리자 로그인 200.

## 제약
- 웹폰트는 외부 리소스라 온라인에서만 로드되며, 차단 시 시스템 폰트로 저하된다.
- 다크모드는 범위 밖(라이트 전용 유지).
